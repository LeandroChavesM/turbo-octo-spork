## Como usar esta documentação

1. Comece pela **Constituição** e pelo **PRD**
2. Siga o **Roadmap** versão por versão
3. Consulte os documentos de dados (GameData / UserData / LocalStorage) sempre que for trabalhar com progresso
4. Use o **Checklist** ao final de cada versão e no final do projeto
5. Mantenha os documentos atualizados se alguma decisão mudar

## Princípio Central

> A documentação é a fonte da verdade.  
> O código deve seguir a documentação, e não o contrário.
